1 はじめに

前の2つの章ではRの基本的な操作方法を解説してきた。ここからは少し進んで、Rを用いた基本的な計量経済分析の方法に焦点を当てながら進んでいく。

本章では、計量経済分析を用いてレポートを作成する際に必要となる記述統計量の表示方法について概説する。

2 事前準備

本題に入る前に、本章で用いるデータを準備する。

{wooldridge}というパッケージをインストールして読み込もう。本パッケージは ``Introductory Econometrics: A Modern Approach’’ という計量経済学の教科書に付属するパッケージであり、過去に計量経済分析を用いて実際に研究された115個のデータフレームが含まれたものである。

3 記述統計量の表示

3.1 そもそも記述統計量とは？

記述統計量とは、データの分布や特徴を要約し、視覚的または数値的に表現するための指標である。実際の計量経済分析に移る前に、利用するデータフレームがどのような形・性質を有しているのかを大まかに示し、その妥当性を読み手に示す役割を持つ。1 主に示される記述統計量として、平均値, 標準偏差, 中央値, 最大値, 最小値, 標本観測数（サンプルサイズ）などが論文において表示される。

3.2 計量経済分析を用いたレポートの流れ

記述統計量は論文のどの節で示すべきなのか？多くの経済学の実証論文において、以下の様な記述の流れが大まかに存在し、学部生もこれらに則ることが望ましいと思われる。

  1. 研究テーマの背景・研究目的
  2. 先行研究の紹介・導かれる仮説
  3. 分析方法（分析モデル）・分析に用いるデータの説明
  4. 分析結果の解釈・分析方法の妥当性に関する議論
  5. 結論

実際の論文では各節がより細分化されており、微妙な流れの違いはあるものの、恐らく皆さんが卒論などで先行研究に触れる際は、上記の様な手順で議論されているだろう。

本章で取り上げる記述統計量の表示は、「3. 分析に用いるデータの説明」の際に示されることが多い。

3.3 記述統計量を表示する関数

いよいよ記述統計量を表示する方法を説明する。記述統計量の表示に有用な関数は沢山あり、本節では以下の関数を紹介する。

  • summary()
  • psych::describe()
  • modelsummary::datasummary()

以下のRコードでは、先ほど説明した3つの変数crmrte, taxpc, polpcの記述統計量を表示する。

3.3.1 summary()

Rに内蔵されている関数であり、summary(データフレーム)で、データフレームに含まれる全ての変数に対する記述統計量を表示する。

# crime4の中にある、3つの変数(crmrte, taxpc, polpc)の記述統計量を表示
summary(crime4[, c("crmrte", "taxpc", "polpc")])

上から最小値 (Min.), 第1四分位数 (1st Qu.), 中央値 (Median), 平均値 (Mean), 第3四分位数 (3rd Qu.), 最大値 (Max.)を示している。2 論文で表示する用途としては微妙だが、分析者自身が初めに確認する用途としては有用である。

3.3.2 psych::describe()

describe(データフレーム)は{psych}パッケージに含まれている関数であり、summary()より多くの種類の記述統計量が表示できる。また、summary()は縦軸が記述統計量、横軸が各変数を示していたが、describe()では縦軸が各変数、横軸が記述統計量を表している。

# psychパッケージのインストール・読み込み
install.packages("psych")
library(psych)
# 記述統計量の表示
describe(crime4[, c("crmrte", "taxpc", "polpc")], 
         # 記述統計量の数を制限
         skew = FALSE)
       vars   n  mean    sd median  min    max  range   se
crmrte    1 630  0.03  0.02   0.03  0.0   0.16   0.16 0.00
taxpc     2 630 30.24 11.45  27.79 14.3 119.76 105.46 0.46
polpc     3 630  0.00  0.00   0.00  0.0   0.04   0.04 0.00

左から、標本観測数 (n), 平均値 (mean), 標準偏差 (sd), 中央値 (median), 最小値 (min), 最大値 (max), 範囲 (range), 標準誤差 (se)が表示されている。skew = FALSEというオプションは、統計量の数を制限するためのもので、このオプションがない場合、歪度 (skewness)や尖度 (kurtosis)などといった比較的マニアックな統計量も表示される。

3.3.3 modelsummary::datasummary()

datasummary(データフレーム)は{modelsummary}パッケージに含まれる関数で、恐らく論文に表示する用途として最も便利な関数であると思われる。以下が基本的な利用方法である。

datasummary(変数名1 + 変数名2 + ...(行を指定) ~ 統計量1 + 統計量2 + ...(列を指定),
            data = データフレーム, fmt = 小数点の桁数を指定,
            title = 表のタイトル, notes = 表の脚注)

先ほどのsummary(), describe()とは違い、記述統計量と変数の指定方法が変数名1 + 変数名2 + ...(行を指定) ~ 統計量1 + 統計量2 + ...(列を指定)という形式である。 fmt =やtitle =といったオプションはなくても実行されるが、論文に載せる際はこれらのディテールにも拘るべきだろう。

実際にcrime4のデータから記述統計量を表示してみる。

# modelsummaryパッケージのインストール・読み込み
install.packages("modelsummary")
library(modelsummary)
# 記述統計量の表示
datasummary(crmrte + taxpc + polpc ~ N + Mean + SD + Min + Median + Max,
            data = crime4, fmt = 3, # 小数点3桁まで表示(4桁目を四捨五入)
            title = "ここがタイトル", notes = "ここが脚注")
ここがタイトル

ここが脚注
crmrte 630 0.032 0.018 0.002 0.028 0.164
taxpc 630 30.239 11.455 14.303 27.792 119.761
polpc 630 0.002 0.003 0.000 0.001 0.036

記述統計量がかなり綺麗な形式で表示されている。3 datasummary()の最大の利点は、拡張性・機能性の高さと、多様な出力形式に対応している点である。上記で説明したオプションの他にも数多くのディテール調整が可能であるため、興味がある方はmodelsummary: Data and Model Summaries in R　Data Summariesを参照されたい。

3.4 記述統計量を別のファイル形式で書き出す

記述統計量を論文に記載する場合、R上で出力した記述統計表を別のファイル形式に変換して書き出す必要がある。書き出す方法は(1)summary(), describe()向けと、(2)datasummary()向けで異なるため、それぞれでの書き出し方法を説明する。

3.4.1 (1) readr::write_csv()

非常に単純な方法として、Rで記述統計量を表示 → csvファイルに変換 → wordなどに貼り付ける、という手順が挙げられる。記述統計量などのデータフレームをcsvファイルに変換する際に使われるのが、{readr}パッケージに含まれるwrite_csv()関数である。

write_csv(データフレーム, 
          "C:/Users/...(保存先のファイルのパス).../記述統計表のファイル名.csv")

実際の例として、crime4のcrmrte, taxpc, polpcに関する記述統計表を、パソコン内のoutputというファイル内に、des.csvという名前で書き出してみる（皆さんが実践する際は、ファイルのパスを各自が保存したいファイル先に指定する）。

# readrパッケージの読み込み(前回の章でインストール済み)
library(readr)

# describe()で作成した記述統計表を、desという名前のオブジェクトに代入する
des <- describe(crime4[, c("crmrte", "taxpc", "polpc")], skew = FALSE)
# 代入した記述統計表をwrite_csv()で書き出す
write_csv(
  # オブジェクト名
  des, 
  # ファイルのパス指定 + 記述統計表のファイル名を決めて入力
  "C:/Users/narita yoshiyuki/Desktop/相澤ゼミ_資料/TA/Aizawa_seminar_TA/R_Studio_lec/output/des.csv")

そうすると、皆さんが各自指定したファイル内に記述統計量のcsvファイルが保存される。

3.4.2 (2) オプションのoutput =を用いる

正直な話、(1)の方法を採用するよりも、素直にdatasummary()を使った方が簡単である。datasummary()内のオプションであるoutput = "C:/Users/...(ファイルのパス).../記述統計表のファイル名.拡張子"を用いることで、datasummary()の関数のみで記述統計表の作成・編集・書き出しを一気通貫で行なうことが出来る。

# 記述統計表を作成し、datasummary.csvというファイル名で保存する
datasummary(crmrte + taxpc + polpc ~ N + Mean + SD + Min + Median + Max,
            data = crime4, fmt = 3,
            # ファイルのパス指定 + 記述統計表のファイル名を決めて入力
            output = "C:/Users/narita yoshiyuki/Desktop/相澤ゼミ_資料/TA/Aizawa_seminar_TA/R_Studio_lec/output/datasummary.csv")

datasummary()の更なる利点として、csvのみならずpngやdocxなどの幅広いファイル形式への書き出しが可能であるという点がある。4

# pngファイルで記述統計量を書き出す
datasummary(crmrte + taxpc + polpc ~ N + Mean + SD + Min + Median + Max,
            data = crime4, fmt = 3, title = "PNG画像で保存",
            output = "C:/Users/narita yoshiyuki/Desktop/相澤ゼミ_資料/TA/Aizawa_seminar_TA/R_Studio_lec/output/datasummary.png")

# htmlファイルで記述統計量を書き出す
datasummary(crmrte + taxpc + polpc ~ N + Mean + SD + Min + Median + Max,
            data = crime4, fmt = 3, title = "HTML形式で保存",
            output = "C:/Users/narita yoshiyuki/Desktop/相澤ゼミ_資料/TA/Aizawa_seminar_TA/R_Studio_lec/output/datasummary.html")

まとめとして、summary()やdescrib()といった関数は、研究者自身が分析を始める前に確認する用途として非常に便利な存在である。一方で、記述統計量をレポートに載せる用途として考えた場合、上記の関数は他のパッケージ・関数がなければ綺麗な表出力が出来ない。そのため、記述統計量を論文に載せる目的としてはdatasummary()を用いることが賢明な方法であると思われる。

脚注

  1. 読み手に示すのみならず、分析者自身が分析を行なう前に記述統計量を確認することで、データに異常（外れ値・欠損値など）があるかどうかを確認することにも役立つ。↩︎

  2. データフレームが欠損値(NA)を含む場合、summary()は各変数のNAの数も教えてくれる。↩︎

  3. summary()やdescribe()を綺麗な形式で出力する場合は、{gt}や{kableExtra}といった表の生成・整形用のパッケージに、作成した記述統計表を渡す必要がある。↩︎

  4. 対応するファイル形式としてhtml, csv, tex, docx, pptx, md, rtf, jpg, pngなどが可能。他にも様々なファイル形式・データ型に対応した出力が可能であり、興味がある方はR上で?datasummaryと打ち込んで実行すれば、画面右下にhelp機能（関数の役割やオプションの説明）が表示される。↩︎
